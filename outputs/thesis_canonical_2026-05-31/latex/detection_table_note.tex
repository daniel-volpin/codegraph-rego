Detection performance on the selected OWASP Benchmark eight-CWE evaluation set (n=454). Per-CWE rows evaluate each category against its mapped Rego rule(s); the Overall row is recomputed over the selected testcase union using any evaluated rule firing as the positive prediction. Because a benign testcase selected under one CWE can fire an off-target rule from another CWE, the Overall row is not the arithmetic sum of per-CWE rows. Summing category rows gives FP=9/TN=212; the union any-rule Overall row gives FP=11/TN=210. violation_count=255 counts emitted rule violations and is not used as the confusion-matrix denominator.
