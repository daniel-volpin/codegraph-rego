# Support

CodeGraph is maintained as a research project. Support is best effort and has no guaranteed response time.

Before opening an issue, read [`README.md`](./README.md) for normal use and [`REPRODUCIBILITY.md`](./REPRODUCIBILITY.md) for setup/evaluation requirements, then search existing issues for the same symptom.

Use the repository's bug form for reproducible defects, feature form for focused improvements, and question form for setup or usage questions. Report vulnerabilities privately as described in [`SECURITY.md`](./SECURITY.md).

Include the CodeGraph version or commit, operating system, relevant tool versions, and a minimal redacted reproduction. Never attach credentials, confidential source code, or private evaluation data.

The maintained installation path is a source checkout on macOS or Linux. CodeGraph remains intended for single-user, loopback-only research use; it is not a supported production service or PyPI distribution.
